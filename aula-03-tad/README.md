# Lista 03 - Tipos Abstratos de Dados (Estrutura de Dados I)

Universidade Federal da Paraíba. Trabalho em C com respostas conceituais e três implementações de TADs opacos.

- `respostas.pdf`: respostas discursivas das questões 1 a 10.
- `respostas.md`: versão editável das respostas.
- `questao-08-matriz/`: matriz dinâmica em bloco contíguo, testes e Makefile.
- `questao-09-complexos/`: operações aritméticas e calculadora com TAD opaco.
- `questao-10-vetor-dinamico/`: crescimento +1 ou x2, contador de transferências potenciais e teste com 100.000 elementos.

Para cada diretório de código: `make`, execute o programa produzido e depois `make clean`.
Todos os projetos usam `-Wall -Wextra -std=c11`.
